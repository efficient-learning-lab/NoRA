# *NoRA*
This repository is the official implementation of NoRA: Normal-Like Reconstruction From Anomaly For Effective Tabular Anomaly Detection. 

## Requirements
This code was experimented with Python 3.9. To set up environments:

```bash
conda env create -f environment.yaml
```
## Train and evaluate
Run the training/evaluation script:
```bash
bash ./scripts/run.sh
```

## Dataset
You can download datasets from [ODDS] and [ADBench].
